# Family Pot — Docs

Shared documentation for the [Family Pot](https://github.com/family-pot) project: product
definition, architecture, roadmap, decisions, and security/threat model, used by
[family-pot-web](https://github.com/family-pot/family-pot-web),
[family-pot-api](https://github.com/family-pot/family-pot-api), and
[family-pot-contracts](https://github.com/family-pot/family-pot-contracts).

Documentation-only issues (new docs, corrections, restructuring) live in this repo. Issues about
a specific repo's setup instructions live in that repo instead.
